# 🎨 Mondrian Grid Project

A simple web project inspired by the abstract paintings of Piet Mondrian, built using HTML and CSS.

## 🚀 Live Demo

👉 https://Chris1-dev.github.io/mondrian-project/

## 🛠️ Technologies Used

* HTML5
* CSS Grid
* CSS Flexbox

## ⚙️ Layout Approach

* Flexbox is used to center the layout
* CSS Grid is used to create the Mondrian-style composition

## 📚 Concepts Practiced

* CSS Grid positioning
* Flexbox alignment
* Layout design
* Spacing and grid areas
